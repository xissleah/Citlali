# cli-basic 0.1.0

Provides citlali.frontend/service-v1; binds one runtime offering text-v1. Native ABI v1 descriptors and public package-local headers. start begins one input thread; request_stop is idempotent and may overlap join. join waits in milliseconds (or UINT64_MAX), returns TIMEOUT while active; repeat join after termination allowed. Other methods serialized. destroy stops and joins before freeing resources. Runtime outlives frontend.

Interactive input submits on Enter, streams the answer, waits internally for completion, then accepts the next prompt. Ctrl+C exits via host stop and orderly cleanup; optional :plan/:quit commands remain. There are no :wait/:cancel commands. EOF exits after completing the current turn. Frontend stop cancels an active operation and joins before releasing it; runtime cancellation remains part of the protocol for shutdown. Config max_tokens 1..4096 and optional prompt for a one-shot invocation. UTF-8 prompt is copied into text request. Worker errors propagate through join and nonzero exit. Sink never retains borrowed event text; cancel does not imply completion. No callbacks may wait/release/destroy/join. Errors must be copied and released before unload; all exceptions contained inside ABI. See sdk protocol semantics and runtime package for inference limits.
