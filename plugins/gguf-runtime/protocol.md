# gguf-runtime 0.1.0

Provides citlali.inference/text-v1; consumes token-decode-v1 and example.gguf/chat-tokenizer-v1. Native ABI v1 uses exact-ID descriptors; public protocol.h and include headers are self-contained. Model identity must match tokenizer vocabulary owner. Config: context_size 128..32768 (default 2048), threads 1..256 (default 4), other keys rejected. CPU-only greedy generation, one active request across sessions; no history, sampling options, tools or adapters.

create_session -> submit -> wait/cancel -> release_operation -> destroy_session. submit copies prompt and returns BUSY with null operation if already active. max_tokens 1..4096, prompt <=1 MiB; tokenized prompt plus limit must fit context. Worker resets KV per request and emits valid UTF-8 TEXT and exactly one terminal event. Sink payloads borrowed only during callback; sink/context retained through terminal wait. Sink nonzero requests cancellation. wait terminal guarantees callbacks ended. cancel only requests stop. release/destroy of unfinished operations is BUSY. Instance destroy stops admission, cancels and joins, then releases decoder and sessions.

Only one waiter and cancel may overlap on an operation. Release/session destroy must be serialized; callbacks cannot wait/release/destroy/join. TIMEOUT returns RUNNING and retains ownership; finite timeout <=86400000 ms or UINT64_MAX. Task failure uses FAILED terminal state/message. request_stop permanently closes admission. plan_summary is immutable, borrowed until instance destroy. Errors released by owning provider; no foreign frees or exceptions crossing ABI. Generation logs timing, not a benchmark against upstream CLI.
